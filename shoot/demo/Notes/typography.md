# Typography for reading

Notes on what makes long-form text comfortable on a screen.

## Measure

The line length that reads most comfortably sits between 45 and 75
characters. Below that the eye returns too often; above it, the return misses
the line it was aiming for.

## Rhythm

Vertical rhythm is the spacing that repeats down the page. When a heading, a
paragraph and a code block all settle onto the same baseline grid, the page
feels composed rather than assembled.

> [!NOTE]
> A rendered Markdown document has no designer standing over it. Whatever
> rhythm it has comes from the stylesheet alone.

## Contrast

Contrast is a ratio, not a colour. Text at `#24292f` on `#ffffff` passes
comfortably; the same text on `#f6f8fa` still passes, which is why a code
block can sit in the flow without the eye stumbling on it.
