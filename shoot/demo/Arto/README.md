# Arto

A reader for Markdown, drawn the way GitHub draws it — locally, offline, and
with none of the editor around it.

## Why

Most of what gets read today is written in Markdown: plans, specs, notes, the
README of every project you clone. It is usually read in an editor, which is
built for changing text rather than for taking it in.

Arto is built for the reading. See [the architecture](docs/architecture.md)
for how a file becomes a page, and [rendering](docs/rendering.md) for what the
engine draws.

## Getting started

```sh
brew install --cask arto-app/tap/arto
arto README.md
```
