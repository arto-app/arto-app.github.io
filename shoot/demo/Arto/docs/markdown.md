# Markdown

The constructs GitHub's dialect carries, close enough together to see at once.

## Inline

*Emphasis*, **strong**, ~~struck through~~, `inline code`, and a
[relative link](rendering.md). A bare URL becomes one too:
https://arto-app.github.io

## Lists

1. Ordered, and nested
   - unordered beneath it
   - which keeps its own marker
2. Back at the top level

- [x] A task that is done
- [ ] One that is not

## Quoting

> A blockquote carries **emphasis** and `code` of its own.
>
> And a second paragraph, indented with it.

## Definitions

Measure
: The length of a line of text.

Leading
: The space between one line and the next.

## Headings

Every heading gets a slug, so [a link to one](#quoting) scrolls straight to
it.
