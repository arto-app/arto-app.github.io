# Keybindings

The shortcuts of the Default preset. Every one of them can be rebound in
Preferences, or in `mappings.json` beside `config.json`.

| Keys | Action | Where |
| --- | --- | --- |
| `⌘K` | Open the command palette | Anywhere |
| `⌘F` | Find in page | Document |
| `⌘J` | Open the contents list | Document |
| `⌘B` | Show or hide the panel | Anywhere |
| `⌘1` | Show the file explorer | Anywhere |
| `⌘2` | Show the reading history | Anywhere |
| `⌘3` | Show the starred documents | Anywhere |
| `⌘4` | Show the documents linking here | Anywhere |
| `⌘[` | Go back | Document |
| `⌘]` | Go forward | Document |
| `⇧⌘F` | Enter or leave focus mode | Document |
| `⇧⌘H` | Highlight the selection | Document |
| `⇧⌘M` | Highlight the selection with a note | Document |
| `⌃]` | Next change since last read | Document |
| `⌃[` | Previous change since last read | Document |
| `⇧⌘Space` | Preview the link under the cursor | Document |
| `⌘+` | Zoom in | Document |
| `⌘−` | Zoom out | Document |
| `⌘0` | Reset zoom | Document |
| `⌘P` | Print or save as PDF | Document |
| `⌘N` | New window | Anywhere |
| `⌘W` | Close window | Anywhere |
| `⌘,` | Preferences | Anywhere |
| `j` / `k` | Scroll down / up | Document (Vim) |
| `g g` / `G` | Top / bottom | Document (Vim) |

## Presets

Default, Vim and Emacs ship with the app, and Clear removes every binding so
you can start from nothing.
